# 🎮 Bingo – Version 1

A simple single-player Bingo web app built using **HTML, CSS, and JavaScript**.

## ✨ Features
- Generates a new 5×5 random Bingo board
- Click tiles to mark/unmark
- Automatically checks:
  - Exact rows
  - Columns
  - Diagonals
- Shows “BINGO!” when a line is complete
- Clean and modern UI

## 📌 How to Run
Just open the `index.html` file in any browser.
